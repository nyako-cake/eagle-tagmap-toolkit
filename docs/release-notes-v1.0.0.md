# v1.0.0 — 首个公开发布

给 Eagle 插件 **Danbooru Tag Assassin** 做的整套改造汇总。
插件本体是第三方作品（作者 KiraraCape-変色君）；整合包经原作者授权发布。

## 一、简体中文界面（新增）

- 新增 `data/i18n/zh-CN.json`：548 条基础词条 + 50 条本次新增 UI 词条
- 新增 `data/t2s.json`：4,321 条繁→简对照（字 + 词），运行时把 `all-tags.json` 里的繁体标签转成简体
- `index.html`：`lang="zh-Hans"`、静态文案转简体、语言下拉新增「简体中文」并置顶
- `plugin.js`：`SUPPORTED_LANGS` 增加 `zh-CN`、`DEFAULT_LANG = 'zh-CN'`、旧的 `zh-TW` 偏好自动迁移到简体、
  `pickLabel()` / `pickTagDisplayLabel()` / `getPartLabel()` 在简体模式返回简体、`s2t()` 在简体模式下改走繁转简
- 除了字符转换，还做了大陆用语本地化：文件夹 / 设置 / 默认 / 加载 / 缓存 / 智能 / 临时 / 配置文件 / 屏幕 / 分辨率 …

## 二、标签映射面板（新增）

- 顶部工具栏新增 **「标签映射」** 按钮
- 可搜索、可筛选（全部 / 仅手写 / 仅自动 / 仅已停用）的映射表
- 行内编辑、`✓` 保存单行、`×` 删除；存空字符串 = **停用**该条（保留英文）
- 写入 `data/local-tag-map.json`；写文件失败时回退 `localStorage`
- **自动映射**：拿图库的 `custom-tags-*.json` 与 Danbooru 中文名做精确匹配
  （去 `角色_` / `Artist：` / `游戏_` 等前缀、去 `（原神）` 这类括注、去结尾「類」），实测建立 214 条
- 手写映射永远优先于自动映射

## 三、多语言 + 拼音搜索（增强）

- 候选输入框支持 **中 / 日 / 韩 / 英 / 拼音** 五种输入
- 新增 `data/pinyin.json`：3,633 个汉字 → 无调拼音（44 KB）
- 全拼 `baifa`、带空格 `bai fa`、首字母 `bf` 都能命中 `white hair（白发）`
- **音节对齐**匹配：`yanjing` 命中「眼镜」，不会先命中「闭着眼睛」（`bi|zhe|yan|jing` 的跨字巧合）
- 结果上限 30 → **200 条**，顶部显示「共 N 个匹配（显示前 200 条）」，底部提示缩小范围
- 候选框改为**悬浮下拉**：`position: fixed` 贴输入框弹出、最高 56vh、点面板外或 `Esc` 收起
- 已映射的候选**标绿**并显示 `→ 你的标签`；点击绿色候选自动带出本地标签，并把下方列表**过滤成该条并高亮**

## 四、模糊「自动匹配」建议（新增）

- bigram 倒排索引 + Sørensen–Dice 相似度，对每个本地标签在 zh/ja/ko/en 四种 label 上取最高分
- 相似度阈值可选 0.60 / 0.75（默认）/ 0.90
- 角色类在两边都带括注时**额外比一次完整字符串**，避免「白露（口袋妖怪）」配到「白露（星穹铁道）」
- 逐条「采用」或「全部采用」，已映射的不会重复出现
- 性能：索引一次性建立约 150 ms，每次分析约 100 ms

## 五、打标写回：不添加未匹配的标签（新增选项）

- 「图片打标」面板新增勾选框，状态持久化在 `meiax_btp_wd14_settings_v1`
- 勾选后，模型输出里没能对上你本地标签的英文 tag **直接丢弃**，只写入命中映射的标签
- 全都没匹配上的图片会被跳过（不清空原有标签）
- 面板上实时显示当前可用映射数量：`N 条自动 + M 条手写`

## 六、标签改名同步（新增）

- 工具栏「同步本地标签」按钮；打开面板时也会自动同步一次（10 分钟内不重复扫描）
- 改名判定：旧清单里消失 + 新清单里出现，且**图库使用次数相同且唯一**才算改名
- 载入时保存 `customTagSnapshot` 快照 —— 改名后旧标签在 Eagle 里是 0 张图，会被插件的「清空空壳标签」删掉，
  没有快照就永远比不出改名
- 同步后被改名的映射**标红并置顶**（`#ff8a8a` 文字、`rgba(232,90,90,.10)` 底色、左侧红条、`改名` 徽章），编辑后自动恢复
- 防呆：扫描结果为空时中止同步，不会清空标签表
- 「继承旧标签」套用时也会顺带做一次改名比对并重建映射

## 七、其它修复

- **启动性能**：`toSimplified()` 原本每次调用都执行 `Object.keys(t2sMap)`，在 1 万多个标签场景下等价于反复重建 4,321 元素数组 ——
  插件启动从 **7.8 s 降到 0.27 s**
- 「合并标签」的候选匹配与展示增加 `zh-CN` 列，简体自定义标签也能匹配到标准标签
- 预置默认 Tagger 路径（`DEFAULT_TAGGER_PATH`），打开打标面板即可直接开始
- `writeTagsToEagleItems()` 增加映射统计（`mapped` / `dropped` 计数）

## 兼容性与限制

- 插件更新会覆盖 `js/`、`index.html`、`data/`，需要按 `docs/features.md` 重新打补丁；
  `local-tag-map.json` 是你的数据，请单独备份
- 一个英文 tag 只能映射到一个本地标签，不支持一变多
- 拼音只覆盖中文标签；日文假名不参与拼音匹配（打 `めがね` 不会命中「眼鏡」）
- 在 Windows + Eagle 4.x 验证通过
